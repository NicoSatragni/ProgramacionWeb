Compras Compartidas, Y Convivencia

Se trata de una lista de compras y artículos comprados. Donde por producto se agrega el precio, la cantidad y luego se puede marcar: "compramos" (pagaron a medias), "compró usuario1" (pagó usuario1), "compró usuario2" (pagó usuario2), etc.
Automáticamente se calcula quién le debe a quién, y cuánto le debe.

Además cuenta con un histórico de compras, y un sistema de turnos aleatorios (ej: "es el turno de... x") que elige al azar a uno de los usuarios para realizar alguna tarea.

La informacion que guardaré sera:
-Lista de compras: Titulo, cantidad.
-Lista Comprados: Titulo, cantidad, precio, pagador (checkbox).
